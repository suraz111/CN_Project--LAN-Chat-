⚡ SOLUTION A • 100% ZERO-INTERNET SETUP

How to Run When There is No Internet Connection

Any smartphone or laptop can act as a local network hub without consuming a single byte of cellular data or internet.

1
📱

Turn On Hotspot

Turn on Personal / Wi-Fi Hotspot on any phone. (Mobile data & internet can be turned OFF or phone can be in Airplane mode!).

2
💻

Connect Devices

Connect your laptop, PC, and other phones to that phone's Wi-Fi network. This creates a secure, local 802.11 LAN.

3
🚀

Start Local Host

On your computer, run start_offline_chat.bat (or python web_main.py). It auto-binds to your hotspot IP.

4
✨

Scan & Chat at 300+ Mbps

Connected phones open the displayed IP (e.g. http://192.168.43.1:8080) or scan the QR code. All assets are 100% local!

🏗️ ARCHITECTURE & PROTOCOL SPECIFICATION

Built with Layered OSI Network Protocols

Engineered strictly with Python standard library sockets, framing headers, and asynchronous event loops.

UDP • Port 50000 Layer 4 Transport

Decentralized Peer Discovery

Broadcasts periodic beacon heartbeats across the subnet mask. Discovers active nodes dynamically without central directories.

TCP • Port 50001 Layer 4 Transport

Framed Direct Socket Streaming

4-byte big-endian length prefix framing prevents TCP concatenation. Transfers 100MB+ binary streams with SHA-256 integrity validation.

HTTP • Port 8080 Layer 7 Application

Mobile Web Client & REST Gateway

Zero-dependency HTTP daemon serving the responsive Vanilla JS SPA, in-memory polling buffers, and real-time event endpoints.

Zero Config Standard Library

No Cloud & No 3rd-Party Libs

Runs out of the box on standard Python 3.10+. No pip installations, no external database, no telemetry, complete data sovereignty.
